# Issue Templates Guide

Recommended issue categories:

## Formula issue

Use when a workbook formula gives an unexpected result.

Required details:

- workbook version;
- sheet name;
- cell or formula;
- expected result;
- actual result;
- source or evidence.

## Source correction

Use when a policy source or source interpretation needs correction.

Required details:

- authority;
- source title;
- source URL or reference;
- affected rule;
- proposed correction.

## Feature request

Use for new workbook features or dashboard improvements.

Required details:

- user problem;
- proposed feature;
- affected sheet;
- expected benefit.
