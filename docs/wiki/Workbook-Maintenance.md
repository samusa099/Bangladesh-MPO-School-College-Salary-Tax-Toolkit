# Workbook Maintenance

## When updating formulas

Update these together:

- formula cell;
- source register;
- data dictionary;
- test case;
- release note;
- wiki page if user-facing behavior changes.

## When updating source rules

Record:

- authority;
- source title;
- effective date;
- extracted rule;
- affected workbook sheet;
- affected cells;
- validation status.

## When creating a release

- verify workbook opens;
- verify tests pass;
- verify source status labels;
- update changelog;
- update package metadata;
- keep previous tax-year workbook unchanged.
