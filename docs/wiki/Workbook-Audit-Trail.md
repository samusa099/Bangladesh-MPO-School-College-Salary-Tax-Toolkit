# Workbook Audit Trail

## Audit principle

Every important workbook result should be traceable from input to formula to source status.

## Minimum traceability

- input field;
- formula sheet;
- output field;
- data dictionary definition;
- source ID if policy-driven;
- validation case if formula-driven.

## Recommended review sequence

1. Check user input.
2. Check sector rule table.
3. Check monthly salary output.
4. Check annual salary output.
5. Check tax calculation.
6. Check dashboard and payslip.
7. Check source register.
