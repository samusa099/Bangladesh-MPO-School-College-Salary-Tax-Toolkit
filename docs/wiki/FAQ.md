# FAQ

## Is this an official MPO salary bill?

No. This is an educational and planning workbook. It is not an official MPO bill.

## Can it file my tax return?

No. It prepares a working estimate and summary only. Final return filing must follow NBR requirements and professional review where needed.

## Why is this only School/College?

Different education sectors use different authorities and policy structures. School/College, Madrasa, Ebtedayi and Technical/Vocational packages should not share one unverified formula table.

## Why are some values editable?

Some policy-sensitive items still require complete source extraction and review. Those values stay editable and labelled Beta/User Input.

## Why no VBA?

Version 1 avoids VBA to improve transparency, compatibility and safety.

## Why separate GitHub and Kaggle packages?

GitHub is for engineering, research and validation. Kaggle is for clean public download and usage.

## What should users edit?

Only highlighted input cells on `USER_INPUT` and intended expense cells on `INCOME_EXPENSE`.

## What must be checked before public Verified release?

- Source register
- Data dictionary
- Test cases
- Official salary-row reconciliation
- Practitioner review
- Formula protection
