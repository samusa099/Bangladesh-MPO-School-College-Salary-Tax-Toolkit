# Getting Started

## 1. Open the workbook

Use the workbook at:

```text
excel/school_college/MPO_School_College_Salary_Tax_BD_TY2026_27.xlsx
```

## 2. Start from `START_HERE`

Read the workbook scope, version and usage notes.

## 3. Fill `USER_INPUT`

Enter only the highlighted input cells:

- employee and institution information;
- designation and grade;
- monthly basic salary;
- allowance assumptions;
- deduction assumptions;
- taxpayer category;
- TDS and annual tax inputs.

## 4. Review outputs

| Sheet | Output |
|---|---|
| `MONTHLY_SALARY` | Monthly gross, deductions and net pay |
| `ANNUAL_SALARY` | Annual salary statement |
| `TAX_CALCULATION` | Tax estimate |
| `TAXPAYER_CATEGORIES` | Category-wise tax comparison |
| `INCOME_EXPENSE` | Expense and savings view |
| `DASHBOARD` | KPI and chart view |
| `PAYSLIP` | Printable payslip |

## 5. Check support sheets

Use `SOURCE_REGISTER`, `DATA_DICTIONARY` and `TEST_CASES` for audit and validation.
