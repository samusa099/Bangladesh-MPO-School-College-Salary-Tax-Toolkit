# Public Release Checklist

## Required before public promotion

- workbook file exists in `excel/school_college/`;
- cover image exists in `assets/previews/`;
- README preview image works;
- source register is complete for verified rules;
- test cases are included;
- no private data is present;
- release note is current;
- package opens correctly after download.

## Recommended release assets

- Excel workbook;
- ZIP package;
- cover banner;
- square icon;
- social preview;
- dashboard preview.
