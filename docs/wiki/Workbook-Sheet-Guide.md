# Workbook Sheet Guide

| Sheet | Purpose |
|---|---|
| `START_HERE` | User entry point and workbook scope |
| `PROJECT_CHARTER` | Project scope, architecture and release rules |
| `USER_INPUT` | Main input sheet |
| `SECTOR_RULES` | School and College MPO rule pack |
| `TAXPAYER_CATEGORIES` | Male, female and special category tax comparison |
| `MONTHLY_SALARY` | Month-by-month salary calculation |
| `ANNUAL_SALARY` | Annual salary statement |
| `TAX_CALCULATION` | Progressive tax estimate |
| `INCOME_EXPENSE` | Annual expense allocation |
| `DASHBOARD` | KPI cards and charts |
| `PAYSLIP` | Printable selected-month payslip |
| `TAX_SUMMARY` | Tax working summary |
| `SOURCE_REGISTER` | Source IDs and extracted rule notes |
| `DATA_DICTIONARY` | Field definitions |
| `TEST_CASES` | Formula validation cases |

## Workbook naming

```text
MPO_School_College_Salary_Tax_BD_TY2026_27.xlsx
```

The workbook is sector-specific. Madrasa and technical education should use separate future workbooks.
