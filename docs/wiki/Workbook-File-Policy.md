# Workbook File Policy

## Main workbook path

```text
excel/school_college/MPO_School_College_Salary_Tax_BD_TY2026_27.xlsx
```

## File policy

- Keep one main workbook per tax year.
- Do not rename released workbooks without a release note.
- Do not overwrite old tax-year workbooks.
- Keep workbook naming consistent with the tax year.
- Store development notes outside the workbook folder.

## Current workbook status

The v0.1.2 workbook includes the taxpayer category variation sheet and remains Beta.
