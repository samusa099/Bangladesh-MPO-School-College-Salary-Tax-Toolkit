# Validation Cases

The workbook includes deterministic formula cases in `TEST_CASES`.

## Main validation groups

- house rent;
- special facility;
- tax threshold boundaries;
- minimum tax;
- bonus calculation;
- increment calculation;
- net pay calculation;
- annual totals.

## Target path

Validation cases may also be stored under:

```text
tests/formula_cases/
```

## Release rule

A public verified release should include 20 to 30 passing cases and official-row reconciliation.
