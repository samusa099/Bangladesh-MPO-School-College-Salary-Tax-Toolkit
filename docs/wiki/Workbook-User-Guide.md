# Workbook User Guide

## Main workflow

1. Open the workbook.
2. Read `START_HERE`.
3. Enter employee and salary data in `USER_INPUT`.
4. Select taxpayer category.
5. Review `MONTHLY_SALARY`.
6. Review `ANNUAL_SALARY`.
7. Check `TAX_CALCULATION` and `TAXPAYER_CATEGORIES`.
8. Enter expenses in `INCOME_EXPENSE`.
9. Review `DASHBOARD`.
10. Use `PAYSLIP` for selected-month output.

## User rule

Do not edit formula cells unless you are maintaining the workbook.

## Maintainer rule

When changing formulas, update the source register, data dictionary and test cases.
