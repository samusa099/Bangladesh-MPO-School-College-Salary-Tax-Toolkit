# Contributing

## Good contributions

- source corrections;
- formula corrections;
- anonymized validation scenarios;
- documentation improvements;
- Excel usability improvements;
- issue reports with clear evidence.

## Do not submit

- real employee personal data;
- bank account information;
- tax credentials;
- NID or sensitive documents;
- unverified formulas presented as final rules.

## Suggested issue format

```text
Problem:
Expected result:
Actual result:
Workbook version:
Sheet name:
Cell or formula:
Source or evidence:
```

## Review expectation

Every formula change should explain the affected sheet, affected rule, source ID and validation impact.
