# Dashboard Guide

The `DASHBOARD` sheet summarizes the workbook outputs.

## Typical dashboard elements

- annual gross salary;
- annual net salary;
- total deduction;
- estimated tax;
- total expense;
- surplus or deficit;
- monthly net salary trend;
- salary component breakdown;
- expense allocation.

## Dashboard purpose

The dashboard helps users quickly understand:

- how salary is allocated;
- how deductions affect net pay;
- how tax compares to income;
- how spending compares to take-home salary.

## Design rule

Keep dashboard charts simple and readable. Do not overload the sheet with too many visuals.
