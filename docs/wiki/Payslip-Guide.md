# Payslip Guide

The `PAYSLIP` sheet creates a selected-month payslip view.

## Input

The selected month should come from the user input sheet.

## Output sections

- employee information;
- designation;
- selected month;
- earnings;
- deductions;
- net pay.

## Important note

This payslip is a planning output from the workbook. Official institution-issued payslips may have different formatting or additional controls.
