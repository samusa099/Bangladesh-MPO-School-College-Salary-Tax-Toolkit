# GitHub and Kaggle Publishing

The project separates engineering work from public distribution.

## GitHub role

GitHub is the engineering workspace.

It should contain:

- workbook source files;
- research documents;
- formula methodology;
- source register;
- validation cases;
- notebooks;
- governance documents;
- release notes;
- issue tracking;
- pull requests.

## Kaggle role

Kaggle is the clean distribution package.

It should contain:

- usable workbook;
- concise README;
- dataset metadata;
- user guide;
- validation cases;
- lightweight notebook;
- preview images.

## Do not upload to Kaggle

The Kaggle package should not include:

- GitHub Actions;
- `.github` workflows;
- temporary files;
- raw personal payroll data;
- credentials;
- NID or bank information;
- duplicate development folders;
- unrelated future-sector files.
