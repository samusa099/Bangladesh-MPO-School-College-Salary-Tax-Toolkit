# GitHub and Kaggle Publishing

The project separates engineering work from public distribution.

## GitHub role

GitHub is the engineering workspace. It contains:

- workbook files;
- research documents;
- formula methodology;
- source register;
- validation cases;
- notebooks;
- governance documents;
- release notes;
- issue and PR workflow.

## Kaggle role

Kaggle is the clean distribution package. It contains:

- usable workbook;
- concise README;
- dataset metadata;
- user guide;
- validation cases;
- lightweight notebook;
- preview images.
