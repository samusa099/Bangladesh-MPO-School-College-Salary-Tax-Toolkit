# Project Positioning

## Portfolio positioning

This project demonstrates:

- Excel product design;
- payroll domain modeling;
- tax calculation logic;
- data dictionary discipline;
- source-linked rule management;
- dashboard design;
- GitHub and Kaggle publishing workflow.

## Target users

- MPO School teachers;
- MPO College teachers;
- payroll/accounting assistants;
- tax-return preparers;
- Excel learners;
- data analytics portfolio reviewers.

## Core value

A free, structured and auditable workbook for salary, tax, payslip and dashboard use cases.
