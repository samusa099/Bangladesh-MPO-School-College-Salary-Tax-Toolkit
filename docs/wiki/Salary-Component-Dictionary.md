# Salary Component Dictionary

## Core components

| Component | Meaning |
|---|---|
| Basic Salary | Base monthly salary used for many calculations |
| House Rent | Housing allowance calculated from basic salary |
| Medical Allowance | Monthly medical allowance value |
| Other Allowance | Additional user-entered monthly allowance |
| Special Facility | Grade-linked special benefit |
| Festival Bonus | Bonus amount in selected month or months |
| Baishakhi Allowance | Bangla New Year allowance |
| Arrear | Prior-period amount paid in the current tax year |
| Gross Pay | Sum of earnings |
| Total Deduction | Sum of deductions |
| Net Pay | Gross pay minus deductions |

## Dictionary rule

Every important component should have a definition, source status and calculation method.
