# Asset Naming Convention

## Preview assets

Use stable names:

```text
cover-banner.jpg
project-icon.jpg
social-preview.jpg
dashboard-preview.jpg
```

## Workbook assets

Use tax-year-specific names:

```text
MPO_School_College_Salary_Tax_BD_TY2026_27.xlsx
```

## Rule

Do not use names such as `final`, `new`, `copy`, `latest` or `updated` in release assets.
