# Workbook QA

## Before publishing

- Open workbook in Excel.
- Confirm no formula errors.
- Confirm dashboard charts render.
- Confirm `USER_INPUT` dropdowns work.
- Confirm `TAXPAYER_CATEGORIES` updates with taxable income.
- Confirm `PAYSLIP` changes when month changes.
- Confirm test cases show expected results.

## File checks

- File name is correct.
- Version number is correct.
- No temporary files are present.
- No hidden private data remains.
- External links are intentional.

## Documentation checks

- README points to the workbook.
- Wiki pages match workbook version.
- Release notes match package contents.
