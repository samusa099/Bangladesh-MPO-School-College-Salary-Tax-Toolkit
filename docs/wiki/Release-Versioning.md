# Release Versioning

Recommended release labels:

- v0.1.0 research pack
- v0.1.1 policy sync
- v0.1.2 taxpayer categories
- v0.2.0 formula hardening
- v1.0.0 verified school college release

## Rules

- Keep every tax year in a separate workbook.
- Do not overwrite prior-year files.
- Update release notes for each published version.
- Keep workbook version, README and wiki version aligned.
