# Sheet Tab Layout Update — 2026-08-13

## Purpose

The workbook previously used long English/technical sheet names. In Google Sheets, long tab names were visually cut off, making navigation hard.

## Fix applied

The workbook now uses short Bengali tab labels with vibrant tab colors.

## Front-facing order

1. `১. শুরু`
2. `২. সারাংশ`
3. `۳. NBR ফর্ম`
4. `۴. রিটার্ন`
5. `۵. বেতন ২০২۶`
6. `۶. আয়-TDS-ব্যয়`
7. `۷. সম্পদ`
8. `۸. পরের বছর`
