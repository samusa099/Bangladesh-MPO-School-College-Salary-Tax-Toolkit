# v0.1.4 Backlog Plan

**Planning status:** Ready for implementation after v0.1.3 verification blockers are cleared.  
**Product status:** Unreleased. This document does not create or publish a v0.1.4 release.

## Planning principles

1. Do not promote unresolved assumptions into verified defaults.
2. Finish v0.1.3 verification evidence before expanding the calculation surface.
3. Keep School & College scope separate from Madrasa, Ebtedayi, and Technical/Vocational rule packs.
4. Prefer small, testable changes with source links and deterministic regression coverage.
5. Preserve Excel 2019-compatible core formulas and the no-VBA v1 policy.

## Explicitly out of scope for v0.1.4

- Integrating Madrasa, Ebtedayi, or Technical/Vocational rules into the School & College workbook.
- Replacing the shared calculation architecture with a large new engine.
- Claiming official payroll, legal, or tax-filing certification without the required verification evidence.
- Adding VBA or opaque automation that weakens auditability.

## Exit criteria for planning issue #34

- Priorities P0–P3 are defined.
- Each material workstream has a dependency or release gate.
- Accepted near-term proposals are separated from out-of-scope expansion.
- v0.1.4 remains explicitly unreleased until implementation, QA, and release governance are complete.
