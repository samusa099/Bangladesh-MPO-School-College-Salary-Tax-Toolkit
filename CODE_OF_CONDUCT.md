# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project respectful, inclusive, and free from harassment.

## Expected behaviour

Contributors should communicate professionally, focus reviews on evidence and project scope, protect private payroll and tax data, distinguish verified rules from assumptions, and correct mistakes transparently.

## Unacceptable behaviour

Harassment, discrimination, personal attacks, deliberate misinformation, disclosure of private data, and repeated disregard for project scope are not acceptable.

## Enforcement

Maintainers may edit, remove, or reject contributions and may restrict participation when conduct threatens contributors, users, data safety, or project integrity.

Report conduct concerns privately through the process described in `SECURITY.md`.

## Scope

This Code of Conduct applies in repository discussions, issues, pull requests, reviews, Wiki contributions, and other project-related spaces.
