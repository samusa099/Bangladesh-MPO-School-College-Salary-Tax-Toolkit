# Minimum Tax Guide

## Workbook handling

The workbook compares calculated tax with the applicable minimum tax assumption.

## Current workbook values

| Taxpayer status | Minimum tax |
|---|---:|
| Regular taxpayer | BDT 5,000 |
| New taxpayer | BDT 1,000 |

## Workbook input

New taxpayer status is selected in:

```text
USER_INPUT
```

## Output

The minimum-tax comparison is shown in:

```text
TAX_CALCULATION
```

## Review note

Minimum-tax handling should be reviewed whenever the tax year changes.
