# Binary Asset Upload Checklist

Use this checklist for large or binary release assets.

## Workbook

```text
excel/school_college/MPO_School_College_Salary_Tax_BD_TY2026_27.xlsx
```

## Preview assets

```text
assets/previews/cover-banner.jpg
assets/previews/project-icon.jpg
assets/previews/social-preview.jpg
assets/previews/dashboard-preview.jpg
```

## Recommended flow

1. Upload or push the workbook.
2. Upload or push preview images.
3. Confirm that README image links work.
4. Confirm that the workbook opens in Excel.
5. Confirm that no temporary files are committed.
6. Tag the release after validation.
