## Upload package

Use the clean Kaggle package, not the full engineering repository.

## Required files

- `dataset-metadata.json`
- `README.md`
- Excel workbook
- validation cases
- user guide
- notebook
- preview images

## Avoid

- credentials;
- temporary files;
- private employee records;
- GitHub workflows;
- development-only folders.
