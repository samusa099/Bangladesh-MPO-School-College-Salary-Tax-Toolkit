# Workbook Security

## Main controls

- avoid VBA in version 1;
- protect formula cells before verified release;
- avoid hidden personal data;
- avoid credentials;
- validate workbook structure before release;
- keep external links intentional and documented.

## Public release scan

Before release, check:

- hidden sheets;
- comments;
- metadata;
- external links;
- temporary files;
- personal data in examples.

## Safe examples

Use synthetic or anonymized data only.
