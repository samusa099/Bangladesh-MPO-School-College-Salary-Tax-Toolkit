# Glossary

| Term | Meaning |
|---|---|
| MPO | Monthly Pay Order for eligible non-government education institution staff |
| Basic salary | Base salary used for several allowance and deduction calculations |
| Gross pay | Total earnings before deductions |
| Net pay | Amount after deductions |
| TDS | Tax deducted at source |
| Tax-free threshold | Income level up to which no tax is calculated for the category |
| Rule pack | Sector-specific salary and tax assumptions used by the workbook |
| Source ID | Workbook reference linking a rule to a documented source |
| Beta | Usable for review, but not yet verified for public reliance |
| Verified | Source-linked, tested, reconciled and reviewed |
