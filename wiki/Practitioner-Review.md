# Practitioner Review

A verified public release should include practical review.

## Review roles

| Reviewer type | Focus |
|---|---|
| MPO/payroll practitioner | Salary component logic and monthly reconciliation |
| Tax practitioner | Tax category, slab, minimum tax, rebate and filing summary logic |
| Excel reviewer | Formula consistency and workbook usability |

## Review evidence

- reviewer name or role;
- review date;
- reviewed workbook version;
- issues found;
- issues resolved;
- remaining limitations.

## Status rule

Without review, the workbook should remain Beta.
