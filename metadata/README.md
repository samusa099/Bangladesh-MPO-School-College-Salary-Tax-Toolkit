# Metadata

This folder stores machine-readable project metadata that supports releases, validation, publishing, and discoverability.

Recommended contents:

- dataset and workbook descriptors;
- tax-year and sector identifiers;
- source-register exports;
- field and sheet catalogues;
- release manifests and checksums;
- Kaggle and GitHub publication metadata.

Metadata must remain specific to this project and must not contain personal payroll, banking, tax-return, national-ID, or confidential institutional data.
