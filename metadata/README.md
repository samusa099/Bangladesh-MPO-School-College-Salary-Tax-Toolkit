# Metadata

This top-level folder stores machine-readable project metadata for releases, validation, publishing, and discoverability.

Recommended contents include project descriptors, tax-year identifiers, workbook and CSV catalogues, source-register exports, release manifests, checksums, and publication metadata.

Metadata must remain specific to this project and must not contain personal payroll, banking, tax-return, national-ID, or confidential institutional data.
