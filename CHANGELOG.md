# Changelog

All notable public-facing changes to the Bangladesh MPO School & College Salary Tax Toolkit are recorded here.

The project uses semantic-style product release identifiers. See `docs/governance/VERSIONING_POLICY.md`.

## [Unreleased]

### Planned / prepared

## [v0.1.3] — 2026-08-13

### Added

- School & College MPO salary and tax workbook for Tax Year 2026–27.
- Taxpayer-category comparison support.
- CSV companion/reference layer.
- Validation scenarios, source-register and data-dictionary support.
- Root-level Wiki documentation and repository governance material.
- Kaggle/Python learning and distribution support.

### Changed

- Improved workbook navigation and tab presentation.
- Added clearer release packaging and documentation structure.
- Strengthened repository validation, privacy and security controls.

### Status

- **Beta**.
- The project remains below Verified status pending authoritative-source extraction, official salary-row reconciliation, deterministic formula validation and practitioner/legal review.

## Version identity note

The canonical current product release is `v0.1.3`.

`v4.0` refers only to a README/design revision and is not a product release version.

The previously published `v2` Git tag is inconsistent with the project versioning policy and should be replaced by a `v0.1.3` tag on the intended release commit.
