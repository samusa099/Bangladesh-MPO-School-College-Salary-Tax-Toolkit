# Notebooks

This folder contains reproducible analysis and validation notebooks for the Bangladesh MPO School & College Salary Tax Toolkit.

Use notebooks for:

- workbook formula inspection;
- CSV and source-register reconciliation;
- tax-threshold and taxpayer-category testing;
- salary-component validation;
- release-readiness evidence.

Notebooks must not contain personal payroll, banking, tax-return, national-ID, or confidential institutional records.
