# User Guide — Kaggle Package

## What this package is

This is the curated `v0.1.3` Beta distribution of the Bangladesh MPO School & College Salary Tax Toolkit for Tax Year 2026–27.

## Recommended workflow

1. Open `MPO_School_College_Salary_Tax_BD_TY2026_27.xlsx`.
2. Begin from the workbook's start/navigation sheet.
3. Enter only the intended user-input values; do not overwrite formula cells.
4. Review salary, tax, summary and reporting outputs after inputs are complete.
5. Use the CSV files for transparent review or analysis outside Excel.
6. Use `notebooks/bd_mpo_salary_tax_toolkit_kaggle_demo.py` for Kaggle/Python exploration.

## Data folders

- `data/csv/` — diff-friendly project reference exports and validation-scenario catalog.
- `metadata/` — project metadata used to describe the distribution.
- `previews/` — stable visual references for the workbook and repository identity.

## Important release status

`v0.1.3` is a **Beta** release line. Defined validation scenarios are not the same as completed verification evidence. The repository still requires 20–30 executed deterministic scenarios, at least 10 anonymized official salary-row reconciliations, completion of authoritative-source extraction, and independent practitioner/legal review before a Verified claim is appropriate.

## Privacy

Do not upload completed personal payroll/tax workbooks, TIN/NID values, bank information, private salary statements, credentials or secrets back to a public Kaggle dataset or GitHub repository.

## Disclaimer

Use the toolkit for learning, planning and transparent calculation workflows. Always verify current legal, tax and payroll requirements from competent official sources and professional reviewers where required.
