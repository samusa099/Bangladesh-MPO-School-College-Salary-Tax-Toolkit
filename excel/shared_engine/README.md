# Shared Calculation Engine Specification

The shared engine supplies reusable logic for:
1. monthly salary calculation;
2. annual salary aggregation;
3. tax-year mapping;
4. income-expense analysis;
5. dashboard and payslip output;
6. validation and reconciliation.

Sector-specific amounts, eligibility, grade mappings, effective dates and deductions belong in sector rule packs. The current implementation is embedded in the School/College workbook; modular extraction is planned before a multi-sector release.
