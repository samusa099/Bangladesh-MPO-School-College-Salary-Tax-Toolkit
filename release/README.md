# Release Workspace

This top-level folder contains version-specific release notes, manifests, checksums, validation summaries, and packaging records for the Bangladesh MPO School & College Salary Tax Toolkit.

## Current public release

- **Canonical version:** `v0.1.3`
- **Status:** Beta
- **Expected Git tag:** `v0.1.3`
- **Expected GitHub Release title:** `Bangladesh MPO School & College Salary Tax Toolkit v0.1.3 Beta`
- **Canonical metadata:** `release-metadata-v0.1.3.json`

The root `RELEASE_NOTES.md` provides the current release overview. Detailed version records belong here.

## Future release material

Files prepared for later versions may remain in this folder before publication, but they must be explicitly marked **Unreleased** or **Release candidate**.

At present, `v0.1.4` Kaggle-safe sheet-order material is preparatory and does not supersede `v0.1.3` until a matching Git tag and GitHub Release are published.

## Required release record

A release should document:

- canonical semantic version and tax-year scope;
- workbook filename and checksum;
- included CSV and documentation assets;
- formula and source changes;
- validation status and known limitations;
- Beta or Verified designation;
- matching Git tag and GitHub Release title;
- matching Kaggle/archive metadata.

See `docs/governance/VERSIONING_POLICY.md` for the repository-wide versioning rule.
