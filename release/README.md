# Release Workspace

This top-level folder contains version-specific release notes, manifests, checksums, validation summaries, and packaging records for the Bangladesh MPO School & College Salary Tax Toolkit.

A release should document the version and tax-year scope, workbook filename and checksum, included CSV and documentation assets, formula and source changes, validation status, known limitations, and Beta or Verified designation.

The root `RELEASE_NOTES.md` provides the current release overview. Detailed version records belong here.
