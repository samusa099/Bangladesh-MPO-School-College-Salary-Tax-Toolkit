# Release Notes — v0.1.3 Tabs and Navigation

This release fixes visible sheet-tab cut-off issues by replacing long sheet names with short Bengali tab names and applying vibrant tab colors. It also adds front-facing Bengali planning sheets for NBR return mapping, return history, assets and next-year carry-forward planning.
