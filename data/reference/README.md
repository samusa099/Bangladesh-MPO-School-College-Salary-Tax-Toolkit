# Reference Data

This folder is reserved for structured, project-specific source and rule metadata that supports the School & College MPO workbook.

## Keep here

- normalized rule metadata;
- source IDs and official document references;
- effective-date mappings;
- data dictionaries that describe reference fields;
- rule-to-formula mapping tables.

## Do not keep here

- raw personal payroll records;
- TIN/NID/bank information;
- unrelated project datasets;
- temporary downloads or duplicate source copies;
- source documents that cannot legally be redistributed.

The authoritative evidence register must distinguish **Verified**, **Needs interpretation** and **Pending evidence** instead of silently treating incomplete research as verified.
